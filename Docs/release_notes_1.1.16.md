# XRoboToolkit v1.1.16 更新说明

发布说明草稿，覆盖近期 PICO SDK 迁移、眼动功能接入及当前本地修正。

## 新增与改进

1. **接入 EyeTracking 注视可视化**：获取双眼合成注视起点和方向，实时显示眼动射线与场景落点。
2. **新增 EyeTracking 结果页**：展示眼动状态、世界坐标起点、方向、命中位置、目标、距离及 SDK 服务返回码；支持从主页面进入和返回。
3. **支持场景与 UI 落点检测**：支持 Collider 和 World Space UI，按最近表面确定落点，并处理遮挡、层过滤和 Rig 自身排除。
4. **明确实时显示频率**：眼动读取、射线求交和可视化按 Unity 渲染帧更新；结果页常规数值刷新为 10 Hz，状态变化和数据失效时立即更新。
5. **新增 Editor 眼动模拟**：支持鼠标或自定义相机局部方向模拟；F8 切换眼动模拟，F9 切换有效性。模拟与真实眼动使用不同颜色及状态标识。
6. **新增 Enterprise EyeFrame 预览**：通过企业服务接收四路原始眼部相机图像，分别显示相机 ID、尺寸和纳秒时间戳，并提供启停及显示方向翻转操作。
7. **调整主界面布局与导航**：整理数据流控制区域，增加 EyeTracking 结果入口和独立 EyeFrame 侧板；页面切换保留已启用的采样状态。
8. **增加诊断与开发验证入口**：补充眼动有效性、服务状态、原生眼位姿和手势输入日志，以及 SDK 迁移、眼动与手势按钮校验工具。
9. **补充开发文档**：新增 EyeTracking 接入指南，并提供注视可视化、EyeFrame 预览及 SDK 迁移说明。

## 修复

1. **修正 Swan 眼动有效性判断**：兼容设备返回的 combined pose 状态位，避免有效数据因只接受状态值 `1` 而被拒绝。
2. **清理失效眼动数据**：无效、关闭、暂停或失焦时清空旧射线与落点；无表面命中时只显示方向线。
3. **完善眼动服务生命周期**：复用已有健康会话，仅停止本组件启动的会话，并在恢复后重新检查服务状态。
4. **适配 SDK 6.1.1 手势射线输入**：改用新版 SDK 的 `pointer/position` 和 `pointer/rotation`，修复迁移后射线未正确跟随手部位姿的问题。
5. **修正 SDK 6.1.1 捏合按钮写入**：按新版 BYTE 按钮格式写入完整按下和释放值，避免按下状态被归一化为低值，影响 UI 点击识别；最终真机点击结果待确认。
6. **修正本地打包参数回退**：未传入外部构建参数时，使用当前 Player Settings 中的版本号、Android version code 和产品名。

## 环境与兼容性

1. 将活动 PICO 包从旧 Integration SDK 3.1.2 迁移至 **PICO Unity SDK 6.1.1**，继续使用 **Unity 2022.3.16f1** 和 PICO XR。
2. 更新 SDK 命名空间及头部、手柄、追踪器、人体追踪、USB 网络和 VST 相关接口适配；保留现有 Head/Controller 采集与传输流程。
3. 保留企业 alpha ToB 客户端与适配层，排除重复企业客户端，并保留应用现有相机库，避免与新版 SDK 相机依赖冲突。
4. 新 SDK 的追踪器及外设标识采用数值设备 ID；现有字符串标识字段保存其十进制值，依赖旧硬件 SN 的接收端或映射配置需要适配。

## 使用说明与验证状态

- EyeTracking 注视数据与 EyeFrame 原始相机图像是独立功能；两者目前均未新增到 TCP 眼动协议或眼动采集文件。
- 当前注视射线计算落点并显示结果，不自动触发注视点击。
- 已有验证覆盖 Unity Editor 导入、Editor/Android C# 编译、坐标转换、表面求交、资源引用，以及 EyeFrame 桥接的合成帧测试。
- EyeFrame 真实采集、像素格式和设备渲染仍需真机验收；眼动校准精度、长期稳定性及完整生命周期也需补充验证。

开发接入步骤见 [EyeTracking 接入指南](eye_tracking_integration_guide.md)；升级差异见 [PICO SDK 6.1.1 迁移报告](../pico_sdk_6_1_1_migration_report.md)。
