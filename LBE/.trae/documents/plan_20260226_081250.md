# 工程 APK 构建指南

该工程包含两个主要部分：Android Library (`LSpaceLib`) 和 Unity 工程 (`LSpaceU3d`)。构建 APK 需要先编译 Android Library，然后将其产物复制到 Unity 工程中，最后在 Unity 中打包。

## 1. 编译 Android Library (`LSpaceLib`)

Unity 工程依赖 `LSpaceLib` 生成的 AAR 文件。

1.  打开终端，进入 `LSpaceLib` 目录。
2.  执行 Gradle 命令编译 Release 版本：
    ```bash
    ./gradlew assembleRelease
    ```
    *或者使用定义好的 task:*
    ```bash
    ./gradlew createReleaseArr
    ```

## 2. 准备依赖文件

编译完成后，需要将生成的 AAR 文件复制到 Unity 工程的临时目录 `LSpaceU3d/libCopeTmp` 中，供构建脚本使用。

**源文件位置 (在 `LSpaceLib` 下):**
- CN 版本: `app/build/outputs/aar/app-cn-release.aar`
- I18N 版本: `app/build/outputs/aar/app-i18n-release.aar`

**目标位置 (在 `LSpaceU3d` 下):**
- CN 版本: `libCopeTmp/cn/blspace_lib.aar`
- I18N 版本: `libCopeTmp/i18n/blspace_lib.aar`

**操作步骤:**
确保 `LSpaceU3d/libCopeTmp/cn/` 和 `LSpaceU3d/libCopeTmp/i18n/` 目录存在，不存在则创建，然后将对应的 `.aar` 文件重命名为 `blspace_lib.aar` 并放入对应目录。

## 3. 构建 Unity APK (`LSpaceU3d`)

1.  使用 Unity 打开 `LSpaceU3d` 工程。
2.  在顶部菜单栏找到 **Build** 菜单。
3.  点击 **Build -> Andriod** (注意菜单拼写为 `Andriod`)。

**构建逻辑说明:**
该菜单会调用 `Assets/Editor/ProjectBuild.cs` 中的 `BuildForAndroid` 方法，它会自动执行以下步骤：
1.  **CN 版本打包**:
    - 将 `libCopeTmp/cn/blspace_lib.aar` 拷贝到 `Assets/Plugins/Android/blspace_lib.aar`。
    - 输出 Debug 版 APK (后缀 `-cn-debug.apk`)。
    - 输出 Release 版 APK (后缀 `-cn-release.apk`)。
2.  **I18N (海外) 版本打包**:
    - 将 `libCopeTmp/i18n/blspace_lib.aar` 拷贝到 `Assets/Plugins/Android/blspace_lib.aar`。
    - 输出 Debug 版 APK (后缀 `-i18n-debug.apk`)。
    - 输出 Release 版 APK (后缀 `-i18n-release.apk`)。

**输出路径:**
默认输出路径为工程根目录上级的 `bin` 目录 (即 `LSpace/bin/localApp-*.apk`)。

## 4. 自动化脚本 (可选)

工程中还提供了一个 Python 脚本 `LSpaceU3d/build_unity_android.py`，用于 CI/CD 流程，支持签名、上传等操作。如果需要在本地模拟 CI 构建，可以参考该脚本的参数进行调用。
